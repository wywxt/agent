## 一、工具接口设计

```java
public interface Tool {
    String name();                    // 工具名称（必须唯一）
    String description();             // 描述文本（纳入 schema）
    ToolCategory category();          // FILE / COMMAND / UI
    Map<String, Object> schema();     // JSON Schema 定义
    ToolResult execute(Map<String, Object> args);  // 执行逻辑
    default boolean shouldDefer() { return false; }  // 是否延迟加载
}
```

### ToolCategory

```java
public enum ToolCategory {
    FILE,     // 文件操作（ReadFile, WriteFile, EditFile, Glob, Grep）
    COMMAND,  // 命令执行（Bash, Agent, MCP tools）
    UI        // 界面交互（ToolSearch, ExitPlanMode, AskUser）
}
```

分类决定默认权限行为——例如 `DEFAULT` 模式下 FILE 类自动允许，COMMAND 类需要询问。

### Schema 生成：延迟加载机制

```java
public List<Map<String, Object>> getAllSchemas(String protocol) {
    var schemas = new ArrayList<>();
    for (var tool : tools.values()) {
        // ★ 延迟工具未被发现 → 跳过，不包含在 schema 列表中
        if (tool.shouldDefer() && !discoveredTools.contains(tool.name()))
            continue;

        // 根据协议转换 schema 格式
        if (isOpenAIProtocol(protocol)) {
            // OpenAI 格式：{type, name, description, parameters}
            schemas.add(openAIFormat(tool.schema()));
        } else {
            // Anthropic 格式：{name, description, input_schema}
            schemas.add(tool.schema());
        }
    }
    return schemas;
}
```

### Deferred Tools 发现

```java
// 1. 按关键词搜索
public List<Map<String, Object>> searchDeferred(String query, int maxResults, String protocol) {
    for (var tool : tools.values()) {
        if (!tool.shouldDefer()) continue;
        if (tool.name().toLowerCase().contains(query)
                || tool.description().toLowerCase().contains(query)) {
            matches.add(tool.schema());
            if (matches.size() >= maxResults) break;
        }
    }
}

// 2. 按名称列表精确查找（支持 select:name1,name2 语法）
public List<Map<String, Object>> findDeferredByNames(List<String> names, String protocol) {
    for (var tool : tools.values()) {
        if (nameSet.contains(tool.name().toLowerCase())) {
            matches.add(tool.schema());
        }
    }
}
```

## 三、内置工具实现

### 3.1 ReadFileTool
- 读取文件全部内容或指定行范围
- 参数：`file_path`, `offset`(行号), `limit`(行数)
- 记录到 `RecoveryState`（压缩恢复用）
- 设置 `FileStateCache`（EditFile 的冲突检测用）

### 3.2 WriteFileTool
- 写入文件（覆盖或新建）
- 记录到 `FileHistory`（支持 rewind）
- 设置 `FileStateCache`

### 3.3 EditFileTool
- 精确字符串替换（`old_string` → `new_string`）
- 如果 `replace_all: true` 则全部替换
- 使用 `FileStateCache` 检测文件是否被外部修改（stale 检测）
- 记录到 `FileHistory`

### 3.4 BashTool
- 执行 Shell 命令（通过 `bash -c`）
- 超时限制（默认 120 秒，可配置）
- 输出截断（`MAX_OUTPUT_CHARS = 10,000`）
- 沙箱模式下通过 `bwrap` 或 `seatbelt` 隔离

### 3.5 GlobTool
- 文件名模式匹配（`**/*.java`）
- 按修改时间排序

### 3.6 GrepTool
- 基于 ripgrep 的内容搜索
- 支持正则、文件类型过滤、上下文行

### 3.7 ToolSearchTool
- 搜索延迟加载的工具（主要是 MCP 工具）
- 支持 `select:name1,name2` 精确加载
- 加载后标记 `discoveredTools.add(name)`

### 3.8 ExitPlanModeTool
- 退出计划模式
- 检查 `planExists()` 确保有计划文件
- 仅在 Plan 模式下可用

### 3.9 AskUserTool
- 向用户展示多选/单选问题
- TUI 模式 → 对话框，Remote 模式 → WebSocket 消息

## 四、MCP 工具包装

MCP 工具通过 `McpManager.McpToolWrapper` 适配到 Tool 接口：

```java
private static class McpToolWrapper implements Tool {
    private final String serverName;
    private final McpSchema.Tool sdkTool;
    private final McpSyncClient client;

    @Override public String name() {
        return "mcp__" + sanitizeName(serverName) + "__" + sanitizeName(sdkTool.name());
        // 例如: mcp__github__search_repos
    }

    @Override public boolean shouldDefer() { return true; }  // ★ 默认延迟

    @Override public ToolResult execute(Map<String, Object> args) {
        var request = new McpSchema.CallToolRequest(sdkTool.name(), args);
        var result = client.callTool(request);
        return isError ? ToolResult.error(text) : ToolResult.success(text);
    }
}
```

// ToolRegistry.createDefault() 创建基础工具集
public static ToolRegistry createDefault() {
    var reg = new ToolRegistry();
    reg.register(new ReadFileTool());
    reg.register(new WriteFileTool());
    reg.register(new EditFileTool());
    reg.register(new BashTool());
    reg.register(new GlobTool());

## 六、工具执行流水线

```
工具调用请求
  → ToolRegistry.get(name) 获取 Tool 实例
  → PermissionChecker.check(tool, args) 权限检查
  → HookEngine.runPreToolHooks(name, args) Pre-tool hook
  → tool.execute(args) 执行
  → HookEngine.runPostToolHooks() Post-tool hook
  → 结果写回 Conversation
  → 结果记录到 RecoveryState（如果是 ReadFile/Skill 调用）
```
