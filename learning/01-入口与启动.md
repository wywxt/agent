# 01 - 入口与启动

## 源码位置

`src/main/java/com/mewcode/MewCode.java` (127 行)

## 功能概述

MewCode 的入口类，负责 CLI 参数解析、配置加载、运行模式分发。是整个系统的"启动器"。

## 核心代码解析

### 1. CLI 参数解析（第 25-51 行）

```java
public static void main(String[] args) {
    String configPath = null;
    boolean remoteMode = false;
    String remoteAddr = ":18888";        // 默认监听地址
    String printPrompt = null;
    String outputFormat = "text";

    for (int i = 0; i < args.length; i++) {
        String arg = args[i];
        if (arg.equals("-p") && i + 1 < args.length) {
            printPrompt = args[++i];           // -p "your prompt"
        } else if (arg.startsWith("-p=")) {
            printPrompt = arg.substring(3);    // -p=your prompt (等号形式)
        } else if (arg.equals("--output-format") && ...) {
            outputFormat = args[++i];          // stream-json | text
        } else if (arg.equals("--remote")) {
            remoteMode = true;
        } else if (arg.startsWith("--remote=")) {
            remoteMode = true;
            remoteAddr = arg.substring("--remote=".length()); // 自定义端口
        } else if (configPath == null) {
            configPath = arg;                  // 第一个无名参数 = 配置文件路径
        }
    }
}
```

支持的参数：

| 参数 | 说明 |
|------|------|
| `-p "prompt"` 或 `-p=prompt` | 非交互模式，输出到 stdout |
| `--output-format stream-json` | 搭配 -p 使用，JSON 流式输出 |
| `--remote` 或 `--remote=:9999` | 启动 HTTP + WebSocket 服务器 |
| `[config-path]` | 显式指定配置文件路径 |

### 3. 三种运行模式分发

```java
// 模式 1: -p 非交互模式
if (printPrompt != null) {
    PrintMode.OutputFormat fmt = "stream-json".equals(outputFormat)
            ? PrintMode.OutputFormat.STREAM_JSON
            : PrintMode.OutputFormat.TEXT;
    PrintMode.run(config, printPrompt, fmt);
    return;
}

// 模式 2: --remote Web 模式
if (remoteMode) {
    var server = new RemoteServer(
            config.getProviders(),
            config.getMcpServers() != null ? config.getMcpServers() : List.of(),
            config.getHooks() != null ? config.getHooks() : List.of(),
            remoteAddr,
            config.isEnableCoordinatorMode()
    );
    server.run();  // 阻塞直到服务器停止
    return;
}

// 模式 3: TUI 终端模式（默认）
var model = new MewCodeModel(providers, mcpServers, hookConfigs, enableCoordinatorMode);
var program = new Program(model);
model.setProgram(program);     // 允许 model 向 TUI 运行时发送消息
program.run();                 // 启动 TUI 事件循环
```

### 4. SIGINT 处理（第 111-118 行）

TUI 框架默认在 SIGINT 时退出。MewCode 覆盖这个行为：

```java
// 用虚拟线程延迟注册（等 TUI 启动完成）
Thread.ofVirtual().start(() -> {
    try { Thread.sleep(500); } catch (InterruptedException ignored) {}
    try {
        Signal.handle(new Signal("INT"), sig -> model.handleSigint());
        // MewCodeModel.handleSigint(): 流式中 → 中断响应；空闲中 → 退出
    } catch (IllegalArgumentException ignored) {}
});
```

### 5. 光标控制（第 109, 122-124 行）

```java
System.out.print("\033[?25l");   // 隐藏光标
try {
    program.run();
} finally {
    System.out.print("\033[?25h"); // 恢复光标
    System.out.flush();
}
```

## 设计要点

1. **极简 CLI**：只有 4 个参数，手动循环解析即可，不需要 picocli 等库
2. **启动即分发**：main() 不做任何业务逻辑，只做参数解析 + 配置加载 + 模式分发
3. **信号处理延迟**：等 TUI 初始化完毕（500ms）再覆盖 SIGINT，避免框架内部状态错乱
4. **光标管理**：finally 块确保退出时光标一定恢复，防止终端状态污染
