## 一、数据结构

### Message

```java
public class Message {
    private final String role;              // "user" | "assistant"
    private final String content;           // 文本内容
    private List<ThinkingBlock> thinkingBlocks;  // assistant 的思考块
    private List<ToolUseBlock> toolUses;         // assistant 的工具调用
    private List<ToolResultBlock> toolResults;   // user 的工具结果
}
```

四种消息类型：

| role | content | 附加块 | 场景 |
|------|---------|--------|------|
| `user` | 用户输入 | toolResults | 用户消息 或 工具结果 |
| `assistant` | 回复文本 | thinkingBlocks + toolUses | AI 回复 |

### ThinkingBlock

```java
public record ThinkingBlock(String thinking, String signature) {}
```

- `thinking`: 思考过程文本（不显示给用户，除非 verbose）
- `signature`: Anthropic API 签名（用于验证思考完整性）

### ToolUseBlock

```java
public record ToolUseBlock(String toolUseId, String toolName, Map<String, Object> arguments) {}
```

### ToolResultBlock

```java
public record ToolResultBlock(String toolUseId, String content, boolean isError) {}
```

## 二、ConversationManager

### 内部存储

```java
public class ConversationManager {
    private final List<Message> history = new ArrayList<>();  // 可变列表
    private boolean ltmInjected = false;  // 长期记忆是否已注入
}
```

### 消息添加方法

```java
// 纯文本消息
addUserMessage(String content)            → new Message("user", content)
addAssistantMessage(String content)       → new Message("assistant", content)

// 带结构块的 assistant 消息
addAssistantFull(text, thinkingBlocks, toolUses)
addAssistantMessageWithTools(text, toolUses)

// 工具结果消息
addToolResultsMessage(List<ToolResultBlock> results)
    → new Message("user", "") + toolResults 设置
```

### 长期记忆注入

```java
public void injectLongTermMemory(String instructions, String memories) {
    if (ltmInjected) return;  // 只注入一次

    var sections = new ArrayList<String>();
    if (instructions != null) {
        sections.add("# mewcodeMd\n..." + instructions);  // CLAUDE.md 内容
    }
    if (memories != null) {
        sections.add("# autoMemory\n" + memories);  // 记忆索引
    }
    sections.add("# currentDate\nToday's date is " + LocalDate.now());

    // 包装为 <system-reminder> 块
    String wrapped = "<system-reminder>\n" + body + "\n</system-reminder>";
    history.add(0, new Message("user", wrapped));  // ★ 插入到第一位
    ltmInjected = true;
}
```

### System Reminder 注入

```java
public void addSystemReminder(String content) {
    // 用于运行时动态注入：任务通知、deferred tools 列表、plan mode 提示等
    history.add(new Message("user", "<system-reminder>\n" + content + "\n</system-reminder>"));
}
```

### 可变访问（设计细节）

```java
public List<Message> getMessages()         → List.copyOf(history)  // 只读快照
public List<Message> getMessagesMutable()  → history               // ★ 直接引用，用于 Layer 1 就地修改
```

`getMessagesMutable()` 是设计关键——ToolResultBudget 需要就地修改 message 中的 ToolResultBlock content，而 CopyOf 会阻止修改。

## 三、消息在 LLM 请求中的转换

在 `AnthropicClient.buildMessages()` 中：

```
ConversationManager 消息          →  Anthropic API MessageParam
═══════════════════════════════════════════════════════════
user + 纯文本                     →  role=user, content=string
assistant + 纯文本                →  role=assistant, content=string
assistant + thinking + tool_use   →  role=assistant, content=[
                                      {thinking, signature},
                                      {text},
                                      {tool_use: id, name, input}
                                    ]
user + tool_results               →  role=user, content=[
                                      {tool_result: id, content},
                                      ...
                                    ]
```

合并规则：连续同角色消息会被合并（API 要求 alternating roles），通过 `mergeConsecutiveSameRole()` 实现。

## 四、压缩后的对话重建

压缩后 `ContextCompactor.autoCompact()` 重建对话：

ConversationManager compacted = new ConversationManager();
